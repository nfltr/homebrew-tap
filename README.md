# nfltr Homebrew tap

```bash
brew install nfltr/tap/nfltr          # the client
brew install nfltr/tap/nfltr-orch     # nodes, hubs and workers
brew install nfltr/tap/nfltr-relay    # your own relay
```

Each formula is generated from a release's signed `SHA256SUMS`: the
signature is checked before any URL or checksum is written. Formulas are
updated with each release; don't edit them by hand.

Docs: https://nfltr.xyz
