# nfltr Homebrew tap

```bash
brew install nfltr/tap/nfltr          # the client
brew install nfltr/tap/nfltr-orch     # nodes, hubs and workers (https://orch.nfltr.xyz)
brew install nfltr/tap/nfltr-relay    # your own relay
```

Each formula is generated from a release's signed `SHA256SUMS` (the
signature is checked before any URL or checksum is written): `nfltr` and
`nfltr-relay` by each nfltr release, `nfltr-orch` by each nfltr-orch
release. Don't edit them by hand.

Docs: https://nfltr.xyz
